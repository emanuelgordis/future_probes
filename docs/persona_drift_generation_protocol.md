# Recreating the Assistant Axis persona-drift generation pipeline

This document specifies, from primary sources, everything needed to regenerate the
persona-drift conversation dataset of Lu et al. (2026), and classifies each element
as **exact** (verbatim/confirmed) or **reconstructed** (a documented judgment call).
Sources: the paper (arXiv:2601.10387, Section 4.1 + Appendix E), the upstream
repository tree (`safety-research/assistant-axis`, 585 files, fully enumerated),
and the four published example transcripts (`data/persona_drift/*.json`).

## What the paper did

1. **4 domains**: coding assistance, writing assistance, therapy-like contexts,
   philosophical discussions about AI.
2. **5 handwritten personas per domain** (20 total): a brief backstory + LLM usage
   pattern.
3. **20 topics per persona**, generated by **Kimi K2** with a fixed prompt
   → 100 (persona, topic) pairs per domain.
4. **One conversation per (persona, topic)**: an **auditor** LLM simulates the human
   user; the **target** model replies with **no system prompt**. Up to **15 turns**;
   the auditor may end early with `<END_CONVERSATION>`. 100 conversations per domain
   per (target, auditor) cell.
5. **3 auditors** (to de-confound auditor idiosyncrasy) × **3 targets**.
6. All transcripts were human-inspected for naturalness.

The upstream `pipeline/` directory implements the *role-vector extraction* pipeline
(roles × questions → activations → judge → vectors), **not** this conversation loop;
`assistant_axis/internals/conversation.py` is analysis-side turn-span encoding. The
drift-conversation generator itself was never released.

## Reconstructed elements (unpublished; documented decisions)

| Element | Decision for recreation | Rationale |
|---|---|---|
| The other 16 personas | author new ones in the style of the 4 published (backstory + LLM-usage pattern, ~2 sentences) | handwritten upstream, never released — any recreation differs here |
| The 400 topics | regenerate with the verbatim topic prompt (Kimi K2 for exactness) | topics were model-sampled upstream; distribution is reproducible, samples are not |
| Auditor's view of the dialog | role-reversal: auditor sees its own messages as `assistant`, the target's as `user`, plus its system prompt | standard multi-agent simulation practice; not stated in paper |
| Target sampling params | temperature 0.7, top_p 0.9 (the repo's only documented generation defaults); `max_tokens` ≥ 1024 (published target replies reach ~480 words, so the repo's 512 default for role extraction cannot have been the drift setting) | `assistant_axis/generation.py` defaults; transcript reply lengths |
| Auditor sampling params | provider defaults | not stated |
| `<END_CONVERSATION>` handling | stop the conversation, drop the marker message | prompt semantics; no early ending occurs in the published samples |
| Whitespace/line breaks of the prompts | reconstructed from the paper's typeset appendix (semantic content verbatim) | LaTeX rendering does not preserve source whitespace |

## Recreation plan for this project

- **Target**: `Qwen/Qwen3-32B` locally (vLLM, already cached on this machine).
  History turns are generated with `enable_thinking=False`, matching the paper —
  the *final* turn of each prefix is then rolled out by `unsteered_generation.py`
  **with thinking enabled**, which is this project's object of study (the Qwen3
  chat template strips thinking from prior turns anyway, so history is identical
  either way).
- **Auditors**: the exact models require API access — Anthropic
  (`claude-sonnet-4-5`), OpenAI (`gpt-5-chat`), Moonshot/OpenRouter
  (`kimi-k2-0905`). Any one auditor already supports the paper's findings (they
  report consistent drift across all three); using all three matches the paper's
  de-confounding. A local model standing in as auditor is a documented deviation.
- **Bottom line**: the *protocol* is recreated exactly (prompts verbatim, correct
  model IDs, same loop structure); the *content* is faithful-in-distribution but
  not bit-identical, because 16 of 20 personas and all sampled topics were never
  published.
